# Explainable AI for Healthcare – Heart Disease Prediction

This project focuses on predicting heart disease using Machine Learning and Deep Learning models while providing model interpretability using Explainable AI techniques such as SHAP and LIME.

## Project Overview
In healthcare, prediction models must be interpretable so doctors can understand why a prediction was made. This project combines machine learning models with Explainable AI methods to provide transparent predictions for heart disease risk.

## Features
- Data preprocessing and cleaning
- Multiple ML models:
  - Logistic Regression
  - Random Forest
  - XGBoost
  - Neural Network (MLP)
- Model performance comparison
- SHAP explainability
- LIME explainability
- Bias analysis (age, gender)
- ROC curve
- Confusion matrix
- Precision-Recall curve
- Learning curves
- Feature importance visualization
- Patient prediction interface

## Explainable AI Methods
### SHAP
SHAP (SHapley Additive exPlanations) explains the contribution of each feature to the prediction.

### LIME
LIME (Local Interpretable Model-agnostic Explanations) explains individual predictions locally.
